# Personal Portfolio Website

A responsive personal portfolio website built with **HTML5** and **CSS3** (with optional JavaScript enhancements).  
This project serves as a digital resume to showcase my skills, projects, and contact information.

---

## Features

- **Profile/Hero Section**  
  Displays my name, role title, and a professional photo/avatar placeholder.

- **About Me Section**  
  A short introduction with 2–3 sentences about my background and interests.

- **Skills Section**  
  Visual grid of technical skills with animated progress bars showing proficiency levels.

- **Projects Section**  
  At least 2 project cards with title, description, and GitHub link placeholders.

- **Contact Section**  
  Includes name, email, and social links (LinkedIn/GitHub icons).

- **Smooth Scroll Navigation**  
  Easy navigation between sections with scroll‑spy highlighting the active link.

- **Consistent Branding**  
  Custom color scheme, typography from Google Fonts, and cohesive design.

- **Responsive Design**  
  Fully optimized for desktop, tablet, and mobile devices.  
  Mobile navigation uses a **hamburger menu** built with pure HTML + CSS.

---

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — responsive layouts, animations, and styling
- **JavaScript (optional)** — scroll‑spy, skill bar animations, typing effect

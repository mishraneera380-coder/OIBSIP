# OIBSIP-WebDevelopment&Designing-Level1-LandingPage

## Project Overview
This project is a **static landing page** built as part of the Oasis Infobyte Internship Program (Level 1, Task 1).  
The goal is to design a visually polished and responsive landing page for a product, service, or brand using **HTML5** and **CSS3**.

## Objectives
- Create a fixed/sticky navigation bar with at least 3 links.
- Design a hero section with headline, subheadline, and call-to-action button.
- Add at least 2 distinct content sections (e.g., Features, About, Testimonials).
- Include a footer with placeholder contact/social links.
- Apply a consistent color palette across all sections.
- Ensure responsive layout using Flexbox or Grid.
- Maintain clean spacing (padding, margin, box-sizing).
- Use readable typography with at least 2 font sizes.

## Tech Stack
- **HTML5** → Structure & semantic markup  
- **CSS3** → Styling, layout, responsiveness (Flexbox & Grid)
